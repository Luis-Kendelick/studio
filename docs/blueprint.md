# **App Name**: FitTrack Lite

## Core Features:

- Student Enrollment: Input and store new student details (name, phone number, email, CPF)
- Student Management: Display a list of students allowing for editing or deletion of their information.
- Schedule View: View student's weekly and monthly schedules on a calendar.

## Style Guidelines:

- Primary color: Use a calming blue (#4A90E2) to establish trust and reliability.
- Secondary color: Light gray (#F0F2F5) for backgrounds and subtle UI elements.
- Accent: Use a vibrant green (#2ecc71) to highlight important actions, such as confirming a schedule.
- Use a clean, card-based layout to organize student information.
- Consistent and clear icons from a set like Remix Icon.
- Use subtle transitions for a smooth user experience.

## Original User Request:
Sou um personal trainer desenvolvedor de software. E preciso criar um app para que eu possa gerenciar meus alunos.
Lá dentro preciso ter as seguintes funcionalidades:
- quero cadastrar novos alunos (nome, telefone celular, email, CPF);
- quero poder apagar alunos ou alterar suas informações a partir de uma listagem de alunos;
- gerenciar em calendário quais são os horários de aulas desse aluno na semana e no mês, dividido por dia;
- quero poder gerenciar informações de planos contratados por eles;
- quero poder visualizar informações de pagamento da mensalidade do mês deles e ser avisado quando não foi paga a mensalidade;

Quero que use React 18 com Vite, TailwindCSS, componentes do shadCN. No back, gostaria que usasse Node.js e Nest.JS. Pode construir com banco de dados PostgresSQL.
